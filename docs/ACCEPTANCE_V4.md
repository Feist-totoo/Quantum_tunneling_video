# Blender V4 验收清单

## 先看审片板

先打开 `renders/qa_v4/v4_camera_correction_contact_sheet.png` 检查 509–1080 帧的机位方向，再查看 `renders/qa_v4/v4_contact_sheet.png`。完整审片板依次覆盖势垒保持、510 帧切镜、粒子跟随、俯视、实虚部分解、三维螺旋展开、Y 向移位、概率密度出现、公式高亮、坍缩与多粒子末段。

## 在 Blender 中检查

1. 打开 `quantum_tunneling_scientific_v4.blend`。
2. 将时间线设为 60 fps 实时预览。
3. 检查 `450–520`：势垒镜头保持到 509 帧，510 帧直接切到粒子新机位，不存在镜头飞向粒子的过渡。
4. 检查 `510–960`：新机位位于粒子与势垒之间，从 XZ 平面以 15° 朝 -X 回看粒子；初始画面上方对应世界 +Z，不得表现为 Y 轴方向。随后连续转到粒子上方，主体持续居中且画面不翻滚。
5. 检查 `1050–1320`：先出现红色实部和蓝色虚部；概率密度不可见；随后蓝色复波函数从平面展开为绕 X 轴的三维螺旋。
6. 检查 `1320–1660`：镜头沿 Y 轴进入原展示位；1560 帧概率密度仍不可见，之后才淡入。
7. 检查 `1740–2040`：三维螺旋和势垒按公式节奏高亮，2040 帧后再进入图表职责区间。
8. 抽查 `2880–4080` 的宽度/高度变化箭头，以及 `4380–5399` 的坍缩和多粒子末段。

## 渲染边界

V4 当前只完成可编辑工程和低清关键帧质检，没有启动最终 1080p60 动画渲染。验收通过后，应输出 PNG/EXR 序列，再使用 FFmpeg 编码静音中间片；不要直接把整段渲染为单个 MP4，以免中断后丢失进度。
