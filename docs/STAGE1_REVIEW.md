# 第一阶段：初步理解与建议

## 项目理解

目标是制作一条完整的量子隧穿科普视频：从太阳核聚变悖论引入，经不确定关系、波函数和势场建立概念，进入 Blender 的量子隧穿核心演示，最后落到 NAND、STM 与芯片漏电应用。除 Blender 段可按实际画面调整外，其余口播基本保持 `脚本.md`。

## 当前素材

- `resource/fromme/1.py`：量子隧穿应用的 Manim 参考，覆盖 NAND、STM、芯片漏电。
- `resource/fromme/2.py`：全片 Manim 框架参考，内部时间规划约超过三分钟。
- `resource/fromme/3.mp4`：不确定关系参考，2560×1440，约 14.39 秒，源帧率约 21.68 fps。
- `resource/fromme/4.mp4`：不确定关系参考，1350×426，18.6 秒，30 fps。
- `quantum_tunneling_scientific_v2.blend`：90 秒 Blender 核心演示。

两段 MP4 的分辨率、比例和帧率都不适合直接进入 1920×1080/60 fps 母版；优先当作运动设计参考，必要时重新制作。

抽帧审查显示：`3.mp4` 的双图结构适合解释位置分布与空间频率分布的权衡；`4.mp4` 的粒子轨迹宽度和动量箭头更具直觉性。建议用 Manim 重做组合版：先从单粒子直觉进入，再变形成上下排列的波包/频率图。这样既保留两者优点，也避免原视频字幕、水印、异常画幅和帧率问题。参考接触表位于 `resource/fromAI/10_review_proxies/fromme_video_contact_sheet.png`。

## 已批准并写入主脚本的科学修订

1. “客服库仑斥力”改为“克服库仑斥力”。
2. 不确定关系改述为：它源于位置和动量算符的不对易；波函数的统计诠释让标准差具有测量分布的意义。
3. `p(x)=psi(x,t)|^2` 改为 `p(x)=|psi(x,t)|^2`。
4. 太阳段讨论轻原子核，核心模型先称“质量为 m 的量子粒子”；到电子类应用时再明确电子，避免物理对象偷换。
5. 势垒内部使用两支倏逝解做边界匹配，不口述为经典粒子到达右端后再次折射。
6. 说明 `T=|F|^2` 使用了入射振幅归一化且势垒两侧波数相同；更一般定义是透射概率流与入射概率流之比。
7. “太阳温度远低于核聚变至少所需一亿度”建议加“按简单经典估算”，因为点火条件还与密度、约束时间和反应截面有关。

## 视觉建议

- 全片统一深黑/深蓝背景、青色物理量、橙色概率密度、洋红色参数变化。
- Blender 保持空间感与粒子叙事；Manim 承担所有公式、坐标轴和数值图。
- 核心段采用左 2/3 Blender、右 1/3 Manim，但重要的波包坍缩与多次试验允许短暂回到全屏 Blender，避免长期小窗削弱冲击力。
- 转场优先使用形态匹配：太阳光晕变温度轴、库仑曲线变势垒轮廓、电子云变波包、概率波的颜色延续到应用段电子轨迹。

## 时间同步建议

所有工具读取 `sync/master_timeline_v3.json` 和 `sync/probability_frames_v3.csv`。统一以 60 fps 和绝对帧号为主键，不依赖剪辑软件中的人工目测。Blender 第 1200 帧、Manim 图层第 0 帧和母版指定帧之间建立明确偏移。
