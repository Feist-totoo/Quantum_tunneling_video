# Blender V4 制作与验证记录

## 本轮目标

V4 只重构量子隧穿 Blender 段的镜头语法与复波函数表现，不覆盖 V3。势垒参数研究、公式同步高亮、坍缩、系综和多粒子末段继续沿用已确认的对象动画。

## 镜头设计

- `0–509` 帧：`CAM_V4_Barrier_Intro` 只负责势垒展示。450 帧后保持势垒构图，不再移动到粒子。
- `510` 帧：唯一一次新增切镜，切到 `CAM_V4_Particle_Wave_Follow`。
- 新机位初始位置严格位于 XZ 平面，`Y=0`；摄影机位于粒子 `x=-31` 与势垒 `x=0` 之间的 `x=-17.5`，朝 -X 回看粒子，实测俯角为 `15.0106°`。
- 初始画面上轴严格采用世界 +Z 在成像平面上的投影，而不是 Y 轴。接近正俯视时，上轴参考平滑过渡到 +Y，离开俯视后再回到 +Z，避免跟踪奇点引发画面翻滚。
- `510–960` 帧：机位跟随粒子沿 +X 运动，并逐步转为粒子正上方的俯视构图。粒子始终由跟踪目标保持在画面中心。
- `960–1320` 帧：俯视构图保持稳定，完成粒子到实部/虚部，再到复波函数螺旋的变化。
- `1320–1560` 帧：同一机位沿 -Y 方向进入原波包展示区域，同时加入 X 向视差，使三维绕轴结构不会在侧投影中退化为单条正弦线。
- `1560` 帧以后仍由同一机位连续运动，后续没有新增硬切或瞬移。

所有机位关键姿态采用自动钳制 Bezier 插值。逐帧验证结果：切镜后最大单帧平移 `0.2418`，最大单帧旋转 `0.6632°`；两者都来自连续曲线，不是跳切。初始画面上轴与 +Z 投影的夹角为 `0°`。

## 复波函数表现

平面分量沿用 V3 的 720 个空间采样点和 151 组传播快照：

- 红线：`Re ψ(x,t)`，位于 XY 平面。
- 蓝线：`Im ψ(x,t)`，位于 XY 平面。
- 三维螺旋：`r(x,t) = (x, Re ψ(x,t), Im ψ(x,t))`。
- 螺旋到 X 轴的半径：`|ψ(x,t)|`。
- 绕轴角度：`arg ψ(x,t)`。
- 概率密度仍单独表示为 `ρ(x,t)=|ψ(x,t)|²`，位于 XZ 平面。

`1050–1120` 帧实部和虚部淡入；`1180–1320` 帧两平面分量拟合为三维复波函数。三维对象使用内部属性驱动直接读取原实部传播权重，因此 151 组快照的时间权重完全一致，不进行近似重采样。

科学校验结果：形变定义最大误差 `1.1921×10⁻⁷`，第 1740 帧形变权重误差 `0`，通过 `1×10⁻⁵` 容差。

## 概率波显隐

概率密度在粒子分解、平面分量和三维螺旋建立期间保持完全隐藏。摄影机沿 Y 轴移动结束的第 1560 帧，透明度仍为 `0`；随后在 `1560–1660` 帧淡入到 `0.42`。这保证观众先理解复波函数，再看到 `|ψ|²`。
