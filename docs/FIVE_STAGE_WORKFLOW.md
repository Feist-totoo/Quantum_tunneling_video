# 五阶段工作流（当前修订）

## 阶段零：自动化工作流

`workflow/deepseek/` 只承担相对独立的文本、简单代码与重复性任务；Codex 负责多模态判断、科学复核、版权复核、软件操作和最终验收。密钥只从本地密钥文件读取，并且只连接 DeepSeek 官方接口。

## 第一阶段：理解与建议

读取 `视频脚本.md` 与 `resource/fromme/` 参考，确定科学口径、视觉风格、章节节奏和不可变约束。除 Blender 段可按画面重排外，台词基本保持原意。

## 第二阶段：工具与技能

配置 Blender、Manim、Remotion、FFmpeg、DaVinci Resolve、剪辑和质检工具；记录版本、来源和测试。IndexTTS 2.5 已配置为本地可选配音工具，但当前主片不生成或嵌入旁白。

## 第三阶段：素材检索与制作

检索公共免费素材并保存来源和许可证；制作 Blender V3、Remotion 数学动画、人物剪影、宏观量子电路、Manim 应用与转场素材。所有类别均用 Markdown 说明用途。当前版本不制作配乐。

## 第四阶段：剪辑制作

建立 1920×1080、60 fps 母版时间线。Blender 主演示采用左 2/3、概率与公式采用右 1/3；应用章节先拉远至宏观电路和 2025 诺奖得主，再推入约瑟夫森结并转入同屏二维总览。主画面保持静音；用户后续提供最终旁白后，只对齐音轨与字幕，背景音乐由用户自行选择。每次审片都输出可回退代理，不覆盖源素材。

## 第五阶段：审查与出厂

检查科学准确性、字幕、节奏、转场、许可、响度、画面安全区、编码和项目可复现性。Blender 完整素材渲染已获用户授权并执行；Remotion/Resolve 成片输出仍需等待用户提供最终旁白和人工画面对齐。
