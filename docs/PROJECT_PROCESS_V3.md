# Blender V3 制作与验证记录

## 目标

V3 专门解决合成适配和镜头连续性：概率密度从 XY 平面移至 XZ 平面，实部与虚部继续位于 XY 平面；删除 Blender 内全部公式和概率图表，为右侧 Manim 图层留出职责边界；整片改为一台连续摄影机。

## 画面修改

- 势垒为纯色长方体，70% 透明，不含内部粒子。
- 画面仅保留 `W`、`V0` 和波函数平面映射标记。
- 概率密度对象 `GEO_Probability_Density_XZ` 表示 `|ψ|²`，位于 XZ 平面。
- `GEO_Wave_Real_XY` 与 `GEO_Wave_Imag_XY` 分别表示实部和虚部，位于 XY 平面。
- 回缩粒子放置在 `x=5.6`；场景内记录了该定位规则。

## 镜头修改

- 删除 V2 的五机位硬切，使用 `CAM_V3_Continuous` 单机位贯穿 0–5399 帧。
- 27 个宽间隔关键姿态均使用 Bezier 插值。
- 粒子段从近似垂直俯视开始，避免跟踪约束轴向奇点后，沿 +X 跟随、转动、拉远并弧形进入侧视。
- 隧穿和参数研究段统一使用近景构图，势垒高度约占画面高度一半。
- 4140 帧后的过渡重新设计，避免 `V0` 与章节标题交叠，再平滑拉近回缩粒子。

## 同步方案

Blender、Manim 和剪辑母版共同采用 60 fps 与绝对帧号。`sync/master_timeline_v3.json` 定义事件，`sync/probability_frames_v3.csv` 提供每三帧概率数据，`scripts/manim_sync_adapter_v3.py` 负责帧号到 Manim 时间的映射。后期无需目测对齐。

## 验证结果

- 工程结构验证全部通过：平面方向、151 组概率密度形态、HUD 清理、同步文件、回缩粒子位置均正确。
- 5400 帧逐帧镜头验证通过：最大单帧平移 0.663，最大单帧转角 1.488°，最大单帧焦距变化 0.070 mm；旧切点附近均无跳变。
- 20 张最终代表帧审片板无自动跳变警告；人工检查通过主体可读性、层级分离、标题安全区与关键构图。
- `final_render_executed=0`，未执行最终动画渲染。
